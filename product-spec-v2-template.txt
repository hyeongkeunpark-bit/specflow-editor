# Confluence 작성 안내

Spec을 Confluence에 올릴 때:

**구조:**
- **1~3번** (문제, 가설, 해결책)은 항상 펼쳐진 상태로 유지합니다. 주간 리뷰 시 이 부분만 읽습니다.
- **4~8번**은 Confluence "펼치기(expand)" 매크로로 감쌉니다. 제목: "4~8. 구현 상세 (펼쳐서 확인)"

**사용자 플로우 (Mermaid):**
- Confluence 편집기에서 `/mermaid`를 입력하면 Mermaid 매크로가 삽입됩니다.
- Spec의 ```mermaid 코드블록 안의 순수 코드만 복사하여 붙여넣습니다.
- ```mermaid와 ```는 제외합니다.

**Prototype:**
- HTML 파일을 Confluence 페이지에 첨부 파일로 업로드합니다.
- 첨부 파일명: `prototype-[제목]-[YYYYMMDD].html`
- 리뷰어는 첨부 파일을 다운로드하여 Chrome에서 열면 실행됩니다.
